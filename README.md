# Мини-учёт оплат учебного центра

FastAPI + SQLite (стандартный `sqlite3`, без ORM). Интерфейс — вариант Б: веб-страница, удобная на телефоне.

## Запуск с нуля

Нужен Python 3.10+.

```bash
git clone <URL-репозитория> payments && cd payments
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

- Веб-страница: http://localhost:8000/
- Swagger (интерактивная документация API): http://localhost:8000/docs
- С телефона в той же Wi-Fi сети: `http://<IP-компьютера>:8000/`

БД (`payments.db`) создаётся автоматически при первом запуске. Другой путь: `DB_PATH=/path/to/file.db uvicorn ...`.

Тесты:

```bash
pytest -v
```

## API

| Метод | URL | Описание |
|---|---|---|
| POST | `/students` | создать ученика `{name, phone, group, monthly_fee}` |
| GET | `/students` | список (необязательный фильтр `?group=A1`) |
| GET | `/students/{id}` | один ученик |
| PUT | `/students/{id}` | изменить (передаются только меняемые поля) |
| DELETE | `/students/{id}` | удалить (его оплаты удаляются каскадом) |
| POST | `/payments` | добавить оплату `{student_id, amount, paid_at?}` (дата по умолчанию — сегодня) |
| GET | `/students/{id}/payments` | оплаты ученика, новые первыми |
| GET | `/debtors?month=YYYY-MM` | должники за месяц (без параметра — текущий) |

Пример ответа `/debtors?month=2026-10`:

```json
[{"student_id": 3, "name": "Вика", "phone": "+998...", "group": "A1",
  "monthly_fee": 400000, "paid": 0, "debt": 400000}]
```

Принятые решения:
- Должник — тот, у кого сумма оплат с датой внутри месяца **меньше** месячной суммы; `debt = monthly_fee − paid`. Ученики с суммой 0 и переплатившие должниками не считаются.
- Переплата не переносится на следующие месяцы (см. улучшения).
- Суммы — целые числа (сумы, без копеек), чтобы не иметь дела с ошибками округления float.
- Список должников отсортирован по убыванию долга.
- Некорректный `month` → 422, несуществующий ученик → 404.

## Что бы я улучшил, будь у меня ещё неделя

1. **Авторизация** — сейчас API открыто. Добавить вход для администраторов (токен/сессия) и роли.
2. **Учёт переплат и «живой» баланс** — переносить переплату на следующие месяцы; учитывать, что у ученика могут быть разные суммы в разные месяцы и даты начала/окончания обучения (сейчас сумма одна на все месяцы).
3. **Миграции и PostgreSQL** — Alembic вместо `CREATE TABLE IF NOT EXISTS`, Docker Compose для запуска одной командой.
4. **Удобство в интерфейсе** — редактирование/удаление учеников и история оплат на странице, поиск и фильтр по группе, кнопка «позвонить»/«написать в Telegram» у должника, отмена ошибочной оплаты.
5. **Telegram-бот** (`/debt`, `/pay`) поверх того же API и уведомления должникам; плюс пагинация списков и больше тестов (граничные случаи, конкурентные записи).
